Chapter 12 Officers & Organizational Board
The municipal seats that govern the market, rendered as a board the Mayor can read at a glance.

The Officers module maintains the organizational chart of the market’s governing structure. It does not control login access — the system has no sign-in — it records who holds which post, so that verification slips carry the right name and the board of officers is always current for an inspection or an audit.

Chapter 13 Verification Slips
The receipt a tenant holds up to prove they paid, and the register the office files.

The system produces two kinds of printable output that serve as verification: utility billing receipts (the slip a tenant keeps) and register sheets (the list the office files). Both are laid out for A4 paper and print directly from the browser.

13.1 When a slip is issued

receipt Billing receipt

Issued when a utility bill (electricity or water) is computed and the officer prints it. A receipt is a quarter of an A4 sheet, so four receipts tile onto one page. A single bill can be printed in up to four labelled copies:

  • Tenant’s Copy
  • Market Office Copy
  • Treasurer’s Copy
  • File Copy
list_alt Register sheet

Available from every list page (stalls, tenants, applicants, billing, violations, logbook, officers). Prints the current filtered view as a numbered table with the municipal seal, a title, the active filters, and a timestamp. A “Checked by” sign-off line is printed at the bottom.

13.2 Issuing a slip

Compute or select the bill
In Utility Billing, either use the Bill Calculator (§7.2) to compute a new bill, or select an existing bill from Billing Records.
Click Print
Opens the Print Preview dialog. A full-size preview of the sheet appears, exactly as it will print.
Enter “Printed By”
The name of the officer issuing the receipt. This is remembered for the next print so you only type it once per shift.
Choose copies
For a single bill: 1 copy (tenant only), 2 copies (tenant + office), or 4 copies (fill the sheet). For a batch: one receipt per bill, tiled four to a page.
Review and print
Verify the preview, then click Print. The browser’s print dialog opens with the sheet ready to send to the printer.
info
Unsaved bills print without a bill number. If you print a bill that has not been saved to records yet, it prints with “Not yet on record” where the bill number would be. Save the bill first if the tenant needs the reference number.

13.3 Anatomy of a printed slip

Figure 13.1 — Receipt anatomy. Each receipt is one quarter of an A4 sheet. Cut along the guides to separate copies. The masthead, reference, and tenant block together identify the charge; the consumption block shows how the figure was calculated.
lightbulb
Late surcharges print automatically. If a bill is both unpaid and past its due date, the receipt adds a surcharge section showing the applicable percentage (3.35% for electricity, 10% for water), the surcharge amount, and the revised total due. No officer action is needed — the surcharge is computed at the moment of printing.

14.2 Export, import & reset

download Export All Data

Downloads civic-market-core-report.json containing every record on this workstation: stalls, tenants, applicants, utility bills, violations, logbook entries, officer seats, and a generation timestamp.

Use it to archive the month, hand data to another office, or move records to a second workstation.

upload Import Data

Reads a JSON file previously exported from this system. Before anything is overwritten, a confirmation dialog shows the incoming record counts compared to what is currently held.

Importing replaces everything. Export the current data first if it has not been filed elsewhere.

delete_forever Reset to Defaults

Erases every record and returns the system to its factory state: the seeded stall register, the ten officer seats, and empty tenant, billing, and logbook tables.

A confirmation dialog names the action and warns that it cannot be undone.

error
Reset is irreversible. The system clears localStorage and resets all sequential ID counters (APP-, TEN-, STL-, OFC-, VIO-, LOG-, BILL-). Any data not previously exported is permanently lost.
lightbulb
End-of-month routine. Before closing the books, open Settings and click Export All Data. File the download in a folder named for the month. If anything goes wrong, you can import it back.

Chapter 15 Support & Help Center
Backup and restore, the FAQ, and a direct line to the development team.

The Support page is the officer’s first stop when something needs explaining. It groups four information cards, a contact directory, the backup facility, and an accordion FAQ.

15.1 Backup & restore

cloud_downloadDownload Full Backup

Open Support
The backup panel shows the current record breakdown: stalls, tenants, applicants, utility bills, violations, and logbook entries.
Click Download Full Backup
The system writes a file named pmrms-backup-YYYY-MM-DD.json containing the complete application snapshot.
File the download
Copy the file to a USB drive, a shared folder, or any safe location. This is your recovery point.

cloud_uploadUpload Backup

Click Upload Backup File
A file picker opens. Select a .json backup previously downloaded from this system.
The system validates the file
It checks for the required record keys (applicants, tenants, stalls, logs, activities). If any are missing, an error message appears and nothing is changed.
Data is restored immediately
A green Data restored successfully banner confirms the operation. All records are replaced with the backup contents.
warning
Restoring replaces all current data. Export the present state first if it contains anything not already saved elsewhere.

Appendix B Troubleshooting by Symptom
When something looks wrong, find the symptom here.
SymptomLikely causeFix
All data is gone after reopeningBrowser storage was cleared (cache wipe, privacy mode, or a different browser)Import the last backup from Support → Upload Backup. Always use the same browser.
Rent shows “Overdue” for a tenant who paidThe payment was recorded under a different period, or the month checkbox was not tickedOpen Tenant Records, find the tenant, and tick the correct month’s checkbox.
Cannot assign a stall to an approved applicantThe stall’s status is not “Available”Change the stall to Available in Stall Management before assigning.
Utility bill shows ₱0.00Previous and current readings are the same, or the rate is zeroCheck the meter readings and the rate in the Bill Calculator.
Import fails with an errorThe file is not a valid export from this system, or it is corruptedUse only .json files produced by Export All Data or Download Full Backup.
Print preview is blankNo bills are selected, or no records match the current filterClear filters or select at least one bill before printing.
Officer tree shows a seat at root level unexpectedlyIts superior was deleted and the seat was lifted to root automaticallyEdit the seat and select a new superior from the dropdown.
Application status does not change after ticking requirementsThe application was already Approved or Rejected — manual decisions override the checklistThis is by design. Only Pending Review and Incomplete respond to the checklist automatically.
Search returns no resultsSearch matches ID, name, and primary fields only — it does not search inside notesCheck that the search term matches a name, stall ID, or record number.
Late surcharge does not appear on the receiptThe bill is either already paid, or the due date has not yet passedSurcharges compute dynamically. They appear only when the bill is unpaid and past due.
“Could not save to browser storage” toastlocalStorage is full (typically 5–10 MB limit)Export a backup, clear old data, or use a browser with a larger storage quota.
