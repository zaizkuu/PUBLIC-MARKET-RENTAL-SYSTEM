Chapter 1 Introduction & System Overview

1.1 About the System

The Public Market Rental Monitoring System (PMRMS) is a desktop application developed for the Market Office of the Municipality of Tanauan, Leyte. It serves as the centralized digital platform for managing all operational aspects of the Tanauan Public Market, including stall management, tenant records, rent collection, utility billing, applicant processing, violation tracking, and official report generation.

info
100% Offline Operation: This system runs entirely on your local computer. No internet connection is required. All data is stored securely on your workstation and never transmitted to external servers, ensuring complete data privacy.

1.2 Key Features at a Glance

dashboard Dashboard

Real-time overview of market operations, revenue, occupancy rates, and recent activity.

storefront Stall Management

Complete registry of all market stalls with status tracking, inspections, and verification slips.

groups Tenant Records

Master directory of stallholders with lease terms, rent collection, and stallkeeper rosters.

person_add Applicant Management

Full application pipeline from intake through document verification to stall assignment.

bolt Utility Billing

Electricity and water meter-based billing engine with receipt printing and batch processing.

gavel Violations

Citation register with demerit point tracking, resolution workflow, and repeat offender monitoring.

analytics Analytics

Formal executive operations report for the Municipal Mayor and Market Board.

forum AI Assistant

Offline intelligent querying assistant for quick answers about rent, stalls, and billing.

4.3 Viewing Stall Details

Click the visibility (eye) icon on any stall row to open the Stall Details View. This formal record sheet displays:

  • Billing History — Table of all utility bills associated with this stall

From this view you can issue a Verification Slip or click Edit Details to modify the stall record.

4.4 Editing a Stall

The Edit Stall form uses a "blank keeps on-record" pattern: all inputs appear blank with the current value shown as a placeholder (e.g., "On record: Meat & Poultry"). Only fields that you explicitly fill in will be updated.

info
Linked Stall Protection: When a stall is linked to a tenant record, the tenant name and certain status fields are locked in the stall edit form. Changes to these must be made through the Tenant Records module instead.

Available fields for editing:

  • Section — Change the market section
  • Status — Update the stall status
  • Business Permit — Update permit status
  • Last Inspection — Set a new date, or use the Inspected Today shortcut button
warning
Releasing a Stall: If you change the status to "Available" on an occupied stall, the system will ask for confirmation and then remove the occupant tenant record, releasing the stall.

4.5 Deleting a Stall

Click the delete (trash) icon to delete a stall. A confirmation dialog will appear.

error
Occupied Stall Protection: You cannot delete a stall that is currently occupied by an active tenant. You must first release or reassign the tenant through Tenant Records before the stall can be deleted.

5.3 Early-Payment Discount (20%)

The system automatically applies a 20% early-payment discount when rent is paid on or before the tenant's due date:

calculate Discount Calculation Rule
  • Each tenant has a configurable Rent Due Day (1 to 28, default: 5th of the month)
  • If rent is collected on or before the due day of the month → 20% discount applied
  • The net collected amount = Monthly Rent × 0.80
  • Both the net collected amount and the discount amount are stored permanently
  • If the due day has not yet passed, the table shows an incentive tag: [₱X] if paid today

Chapter 7 Utility Billing

The Utility Billing module is the meter reading calculation and billing engine for Electricity and Water utilities across all market stalls.

7.1 Bill Calculator

The embedded Bill Calculator at the top of the page allows you to create new utility bills.

Utility Rates

UtilityRateUnitLate Surcharge
bolt Electricity₱11.50per kWh3.35%
water_drop Water₱25.00per cu.m10.00%
calculate Billing Formula

Consumption = Current Reading − Previous Reading (minimum 0)
Amount Due = Consumption × Rate per Unit

How to Create a New Bill

Select Utility Type
Toggle between Electricity and Water. The system automatically loads the correct rate, unit labels, and icon.
Select Stall & Tenant
Choose a stall from the dropdown — the occupant tenant, last recorded meter reading, and meter number are auto-filled. Alternatively, select a tenant to auto-select their stall.
Set Period Covered
Enter the Period From and Period To dates. Use the Cover all of [Month] button to quickly set the first and last day of the current month.
Set Due Date
The due date defaults to 15 days after the period end date. You can adjust this manually.
Enter Meter Readings
The Previous Reading is auto-populated from the last bill on record. Enter the Current Reading. The system validates that readings are not negative and that the current reading is not less than the previous reading.
Review the Live Calculation
A real-time summary card displays: stall, tenant, meter number, period range, readings, consumption, rate, and total amount due. If the due date has already passed, a warning shows the computed late surcharge.
Save or Print
  • Save to Records — Posts the bill, writes a Logbook entry, and updates meter info if needed
  • Print Receipt — Opens the Print Preview for immediate receipt printing
  • Clear — Resets the calculator
warning
Duplicate Detection: If a bill already exists for the same stall, utility type, and billing period, the system will show a confirmation modal asking whether you want to proceed or cancel.

7.4 Late Surcharges

warning Late Surcharge Rules
  • Electricity: 3.35% surcharge on the billed amount after the due date
  • Water: 10.00% surcharge on the billed amount after the due date
  • Surcharges are calculated dynamically at the time of printing — they appear on the receipt if the due date has passed, but the original ledger amount remains unchanged
  • This ensures historical records are accurate while printed receipts reflect the current total owed
info
"Printed By" Memory: The system remembers the issuing officer's name from the last print session, so you only need to enter it once. The name is stored in localStorage and persists across sessions.

Chapter 11 Market Assistant (AI)

The Market Assistant is an offline intelligent querying tool that allows officers to ask plain-language questions about rent, stalls, bills, tenants, and violations — and receive accurate, data-driven answers.

11.1 How It Works

The assistant uses a two-tier engine to ensure accuracy:

Tier 1 — Deterministic Pattern Matching

Your question is first analyzed against keyword patterns for 12 core market intents. If a strong match is found, the system pulls the answer directly from the database using precise calculations — no AI guessing.

Tier 2 — Local AI Model (Optional)

If keywords don't match clearly, the system may use a local AI model running entirely on your computer to classify your intent. The AI can also rephrase factual answers into natural conversational language.

lightbulb
Data Accuracy Guarantee: All figures (amounts, counts, names) are never generated by AI. They are always computed by the system's deterministic business logic. If the AI rephrases an answer and any number or name doesn't match the computed facts, the AI phrasing is automatically discarded and the verified record text is shown instead.

Verification Slips are official clearance documents issued by the Market Office to stallholders. These slips are presented to the Business Permit & Licensing Office (BPLO) for business permit issuance or renewal.

13.1 Accessing the Verification Slip Feature

There are two ways to issue a verification slip:

  • From Stall Management — Click the Stall / Space Verification button in the header, or the fact_check icon on a specific stall row
  • From Stall Details View — Click the "Issue Verification Slip" button

13.2 Issuing a Verification Slip

Select Purpose
Choose either:
  • Renewal — For existing lessees renewing their business permits (auto-ticks relevant checklist items)
  • Issuance — For new lessees obtaining their first business permit
Fill In Slip Details
  • Issued By — Market Supervisor name (remembered across sessions)
  • Issued To — Stallholder's name (auto-filled if launched from a specific stall)
  • Section — Market section (auto-filled)
  • Stall No. — Stall number (auto-filled)
Check Requirements
Tick the applicable items from the 8-point checklist:
  1. Latest Business Permit (Original)
  2. DTI Registration
  3. OR of Last Monthly Rental Paid
  4. OR of Last Electric/Water Bill Paid
  5. Meat Inspector's Clearance
  6. Existing Lessee
  7. Inspection of Stall
  8. New Lessee

An "Others" field allows entering additional custom requirements.

Select Slips Per Sheet
Choose how many slips to print per A4 sheet: 1, 2, or 4 slips.
Print

info

Printed Slip Contents

Appendix A Business Rules Quick Reference
RuleDescription
Monotonic ID Counters All IDs (STL, TEN, APP, UTL, VIO, OFC, SSV, LOG) are sequentially assigned and never reused — even after deletion. This prevents historical misattribution.
20% Early Rent Discount Paying rent on or before the due day (default: 5th, max: 28th) earns a 20% discount. The net collected amount and discount value are stored separately as permanent records.
Dynamic Late Surcharges Electricity: 3.35% surcharge; Water: 10% surcharge. Calculated at print time when the due date has passed. The original ledger amount is never altered.
Stall-Tenant Linking Assigning a tenant marks a stall as "Occupied". Moving a tenant releases their previous stall to "Available". Deleting an occupied stall is blocked.
Organizational Hierarchy Safety Circular dependencies, self-references, and orphaned seats are automatically prevented. Deleting an officer reassigns their subordinates to the deleted officer's superior.
Edit Pattern ("Blank Means Keep") All edit forms open with blank inputs displaying current values as placeholders. Only explicitly typed fields are updated on save.
Verification Slip Validity All verification slips are strictly valid for 7 days from the date of issuance.
Duplicate Bill Detection The system warns if a utility bill already exists for the same stall, utility type, and billing period.
Philippine Standard Time All dates and times use PHT (Asia/Manila, GMT+8). The live clock and all timestamped entries reflect this timezone.
Offline Operation The system makes zero network requests. All fonts, icons, and data are stored locally. Internet is never required.

Appendix B Troubleshooting & FAQ
ProblemSolution
The application won't start Ensure Windows 10 or later is installed. Try right-clicking the application shortcut and selecting "Run as administrator". If the issue persists, reinstall the application.
Data appears missing after reopening Data is stored in %APPDATA%\Tanauan Public Market System. If you cleared your browser/app data, you may need to restore from a backup file using the Support page.
Cannot delete a stall Stalls that are currently occupied by an active tenant cannot be deleted. First release or reassign the tenant through the Tenant Records module, then delete the stall.
Print output is misaligned Ensure your printer is set to A4 paper size with Portrait orientation. In the print dialog, set margins to "Default" or "None" and make sure "Scale to fit" is disabled.
Rent discount was not applied The 20% discount only applies when rent is collected on or before the tenant's due day. Check the tenant's Rent Due Day setting in their record details.
Search returns no results Ensure your search term matches the field you're searching (name, ID, section, etc.). Try clearing filters first, as active filters may limit search scope.
Transfer data to another computer Use Support → Download Full Backup to export your data. Copy the backup file to the new computer via USB drive. Open the app on the new computer and use Support → Upload Backup File to restore.
Market Assistant shows "Records only" mode This means no local AI model is loaded. The assistant still works fully using direct database queries. To enable AI phrasing, place a compatible GGUF model in the resources/models folder.
Notifications bell shows wrong count Notification counts are calculated live from current data. If counts seem incorrect, check that the underlying records (overdue rent, pending applications, etc.) are up to date.
Application is running slowly Close other applications to free system resources. If the database has grown very large, consider exporting data for archival and resetting to defaults for the new period.
