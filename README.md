# Public Market Rental Monitoring System

Local-first admin dashboard for tracking tenant applicants, tenants, violations, utility usage, logbook entries, analytics, archives, and downloadable reports.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Current scope

- Fully offline browser app
- Mock seed data stored in local state and persisted to `localStorage`
- Dashboard, applicants, stalls, tenants, violations, billing, logbook, analytics, archives, and reports modules
